# AGENTS.md

## Commits

- Format: [Conventional Commits](https://www.conventionalcommits.org/) with a scope, `type(scope): summary`, e.g. `fix(voice): …`, `feat(sing): …`, `docs(readme): …`.
- No attribution of any kind: no `Co-Authored-By`, no "Generated with …", no AI tool names, links or emoji, in commits, pull requests, code or docs.

## Identity

- Commits and pull requests are made under the repository owner's own identity, so only humans appear as authors and contributors.
- Never change the git identity (`git config user.*`), pass `--author`, or commit, push or open a pull request as an AI or bot account.
