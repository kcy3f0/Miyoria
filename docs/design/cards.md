# 她給你的卡:抽卡與立繪

2026-11-09 起草。現況見 `packages/api/src/card.ts`、`packages/card-face`、`docs/OPERATIONS.md` 的卡片段落。

## 0. 一句話結論

立繪不再是 10 張固定截圖。發卡時用她的 Live2D 模型在機器上現場擺出一個姿勢、拍一張去背圖:表情跟著關係,手上的東西、配件、角度、背景照公開的機率抽。每張卡都長得不一樣,有稀有度,慢慢長成收藏;但卡還是「她眼中的你」的快照,不拿來交易。

## 1. 現況

- 一天最多 5 張,每張是發卡當下關係的快照:分級文字、她寫的一句話、印章、她選的欄位。
- 立繪 10 張(`card-<pose>.local.webp`,同一套衣服、同一個角度,只有表情不同),依好感分組(`CARD_POSES`),組內隨機。
- 付費:重抽、指定立繪、框(sakura / abyss / gold)、閃卡。幣只能賺,不能用真錢買,也不能轉給別人(`economy.md` §2)。

變化太少:抽幾張就看完了。

## 2. 原則

1. **模型檔不出機器。** 算圖在跑 Core 的機器上用無頭瀏覽器跑,只把 PNG 放進卡片。moc3 和貼圖不放上網頁。
2. **表情說真話。** 表情由關係決定,稀有度買不到、抽不到。好感很差的人不會抽到愛心眼。
3. **機率公開。** 每個池子的機率寫在卡片頁上,改機率要留紀錄。幣不碰真錢,所以法規上不是抽卡,但照抽卡的規矩做。
4. **稀有度不是好感。** 抽到 SSR 不代表她比較喜歡你,也不影響任何數值。
5. **卡是給你的,不能交易。** 卡上有你的名字、她怎麼叫你、她對你的感覺。轉給別人就不是那張卡了,而且開放交易就會有人開小號刷卡轉給大號,和「幣不能轉給別人」的理由一樣。

## 3. 一張卡由什麼組成

| 特徵 | 怎麼決定 | 模型裡的東西 |
|---|---|---|
| 表情 | 關係(好感分組),她在組內挑,或對方付費指定 | 臉紅、愛心眼、> <眼、屑屑眼、流冷汗、落淚、圈圈眼、黑臉、大牙、微笑等參數 |
| 手 | 抽 | 無、狗尾草、撫胸、豎食指 |
| 配件 | 抽(可以沒有) | 黑框眼鏡、單片眼鏡、大鋼盆、尾巴 |
| 服裝 | 抽 | 長短裙、鞋子、胸口衣服 |
| 角度 | 每張隨機,在安全範圍內 | 頭的 X/Y/Z、身體、視線 |
| 背景 | 抽 | 見 §5 |
| 框、閃 | 付費(照舊),SSR 自帶閃 | |

「大小變」「加載」這類特效先不放,看過算圖再決定。

## 4. 稀有度

先抽稀有度,再從那個稀有度允許的池子抽特徵。這樣機率表簡單,公開時也好懂。

| 稀有度 | 機率(草案) | 允許的東西 |
|---|---|---|
| N | 70% | 基本角度、無配件或一般配件、一般背景 |
| R | 22% | 加上手部動作、服裝變化、較少見的背景 |
| SR | 7% | 加上稀有配件(單片眼鏡、大鋼盆)、特殊背景 |
| SSR | 1% | 特殊背景、自帶閃卡、可能有配件組合 |

卡上會標稀有度,卡片頁列出這張卡抽到了哪些特徵。

## 5. 背景

不用遊戲美術。先用程式畫的:她的顏色的漸層、光斑、星點、水面、夜空,每種有幾個變化。之後 owner 有自己的圖(委託或自己畫的)再加進池子。

限定池(之後):她直播中發的卡才會出現的背景、節日、她的生日、唱到第 N 首歌之類跟她生活有關的時刻。

## 6. 算圖

- 一個獨立的頁面,用 Live2D 官方 Cubism SDK for Web(她的模型是 Cubism 5,moc3 v5)。Cubism Core 是 Live2D 的授權軟體,個人和小規模使用不用另外簽約,但要同意條款。
- Core 用 playwright-core 開無頭 Edge 載入這個頁面,傳入特徵(參數值、表情、動作的某一格),等一幀畫好,拍一張透明背景的 PNG。
- 模型從 VTube Studio 的資料夾複製一份到 `data/`(不進 git),貼圖縮到 2048,算圖比較快。
- 發卡時算一次,存成 `data/cards/<編號>.png`。特徵也存在卡的快照裡,圖不見了可以重算出一模一樣的。
- 算圖器不在或失敗時,退回現在的 10 張立繪,卡照樣發得出來。

## 7. 往卡牌遊戲走(分階段)

1. **這次:** 現場算圖、特徵、稀有度、公開機率。
2. **卡冊:** 每個人看得到自己集到哪些特徵(圖鑑),集滿一個系列(例如「眼鏡系列」)給稱號。只看自己,不排名(面板規則:不排名任何人)。
3. **限定池:** §5 的限定背景和活動。
4. **玩法(待定):** 卡不拿來比強弱。如果數值來自關係,就等於把關係變成戰力,和「不排名」衝突。可以想的方向:拿卡和她互動(給她看某張卡,她會記得那天)、合成同系列的卡換特殊背景。

## 8. 要 owner 決定的事

- 稀有度機率(§4 是草案)。
- 交易:我的建議是不做(§2.5)。
- 「黑臉」「落淚」「圈圈眼」這種表情給哪些關係,還是只當 SR 以上的彩蛋。
- 付費指定立繪(`card_pose`)以後指定的是表情,還是整組特徵。
- 舊卡保持原樣。
- 模型授權:DeepSeek-chan 模型能不能拿來產生公開的卡片圖(直播已經在用,應該沒問題,但要確認作者條款)。
