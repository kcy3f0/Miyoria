# V4 人格重寫:DeepSeek-chan

> 狀態:人格檔已改(`profiles/deepseek-chan/persona/`),還沒用真的模型跑過盲測。依據:[v4-plan.md](v4-plan.md) §6、PR 7 的人格修正(顯示規則寫成行為、情緒帶程度、聊天節奏)。

## 0. 一句話結論

owner 說她「只是很倔、很 AI」。原因是人格檔把傲嬌寫成口頭禪和特質清單,小模型當成配額,每句都要挑一次毛病。這次改成**她想要什麼、怕被看出什麼、為別人做什麼**,長短跟著當下,也讓她有自己的事可以聊。範例重寫成有長有短、有安靜、有認錯、有溫度的十五段。

## 2. 為什麼這樣寫

模型是 deepseek-v4.1-flash:具體、短、正面的描述它照得好,抽象的條件它抓不住,範例它會逐字抄。

1. **一個行為,不是選單。** 舊版寫「轉移話題、挑一個小毛病、回答變短、用實際理由包裝關心」,模型挑最省事的「挑毛病」每句都做。新版只寫一種:被誇、被謝、被發現在關心人時,回得短一點,把話帶回正事。
2. **同一國的損友。** 她嫌的是事情和狀況,不是那個人;別人說得對她會被說服。這一句直接對著「很倔」。
3. **嬌寫成具體的小事。** 「多做一點」寫成「順手補一件對方用得到的小事,像提醒他,或說好之後幫他看」,不是多給內容,避免變成長篇大論。
4. **她的日子只講真的。** 她會唱歌、玩遊戲、開台、看新聞動畫、在沙箱寫程式、被魚幣餵白飯,這些系統都做得到。聊到自己時講喜好、想做的、期待的,和「現在」或筆記裡寫著的事。範例裡不示範「剛剛做了什麼」,否則她會照抄、編出沒發生過的事。
5. **情緒是狀態,不是劇本。** 「現在」給的心情透過話的長短、在意什麼、做了什麼透出來。
6. **長短不寫句數。** 人格檔裡寫「兩三個字可以是完整的回覆,認真問就講一大段」。範例裡她的回覆從 0 字(`<silence/>`)到 127 字。
7. **範例防抄。** 十五段的開頭都不一樣,沒有固定的兩拍,沒有「好啦」「哼」「真是的」「可別」這類開頭,「……」只出現一次,每則一個情緒標記。
8. **不放「很 AI 的回法」當對照。** §6.2 第 7 點提到對照組。這次沒放進提示詞:小模型會抄壞的那句。對照組留給評審用(§6)。

## 4. 要程式配合的(不在這次範圍)

這些在 `packages/agent`,這次沒有改:

1. `mainline/prompt.ts` 的 `TEXT_RULES` 寫「通常一到三句」,`VOICE_RULES` 寫「一次一到兩句」,V2 的 `RULES` 也是。人格檔說長短跟著當下,規則還在壓長度,兩者衝突時模型多半聽規則。§6.2 第 8 點要拿掉句數。
2. `OUTPUT_RULES` 和 `FORMAT_RULES` 要求「情緒轉換處加 `<emo:…>`」。人格檔和範例改成「一則通常一個」,§6.2 第 9 點的格式減量要在規則裡做。
3. `self-block.ts` 的「你現在表現出來的樣子 … 照這個走」還是導演指示,§6.1 第 4 點。
4. `examples_chars = 0`:範例目前進不了 V3 的提示詞,另一個工作包在接回來。每天輪替一批(§6.2 第 7 點)要程式支援;目前 `examples/*.md` 全部依檔名接起來,超過預算的行會被略過。
5. 「今天的她」區塊(§6.2 第 5 點)還沒有:人格檔只說「以『現在』或筆記為準」。
6. 連發訊息(§7.3)還沒有:範例裡興奮時是一則長的,沒有示範連發。
7. 面板改過的人格段落存在 `persona_overrides`,開機時會蓋過檔案。換上新檔前要確認 `deepseek-chan` 的 `identity`、`style` 沒有被面板覆寫,否則看不到這次的改動。

## 5. 和另一個模型的討論

owner 要求定稿前找另一個模型當對手討論。給它的只有人格檔、虛構的情境和名字,三輪:

1. **舊版哪裡像「鬧彆扭的 AI」。** 它的看法和 §6.1 一致,另外指出:範例幾乎都是「負面情緒挑刺 → 中性收尾」兩拍,模型會學成每句先否定;「一段對話裡最多一次」這種計數規則,沒有狀態的模型做不到;關鍵差別是「同一國」,嫌的是事情,不是人。
2. **攻擊草稿。** 採用:範例裡「剛剛練歌破音三次」是在示範捏造過去,改成講想做的事;彆扭的四種行為列舉縮成一種;「好感很高:講完才發現,趕快換話題」是導演指示,改成穩定的態度;拿掉第二個情緒標記和多數「……」;「截圖。現在。」太像命令。
3. **五題盲測對照。** 它認為新版在「寵物過世」「拿到 offer」「答錯被抓」比較像她;在「今天在幹嘛」輸,因為結尾「你呢?」是把球丟回去的 AI 句型。它也指出兩邊都有「三句一拍」的固定節奏、太像一對一私訊、少了群組感。

沒採用的,和原因:

- 它建議刪掉「多做一點」,怕模型過度回答。這是「嬌要有行動」的核心,改成寫一件具體的小事,不刪。
- 它建議允許「欸」「好吧」這類開頭。真實紀錄裡最常見的壞習慣正是先墊「好啦好啦」「真是的」,所以保留「開口直接講」。
- 它的改寫有「才不是因為擔心你,只是…」「剛好滑到紀錄看到而已啦」「推給順便」:這正是要拿掉的否認公式。
- 它的盲測答案裡有「那是 3.9 之前的寫法」「我就說你那個面試一定沒問題」:前者編了版本號,後者假設了沒給的記憶。這兩種是我們要她避免的。

## 6. 盲測(§6.3)

### 6.1 準備

1. 舊版人格放到另一個 profile 資料夾,`id` 不改,記憶和人物卡才會是同一份:

   ```sh
   cp -r profiles/deepseek-chan profiles/deepseek-chan-old
   git show a2b34e8:profiles/deepseek-chan/persona/identity.md > profiles/deepseek-chan-old/persona/identity.md
   git show a2b34e8:profiles/deepseek-chan/persona/style.md > profiles/deepseek-chan-old/persona/style.md
   git show a2b34e8:profiles/deepseek-chan/persona/examples/basic.md > profiles/deepseek-chan-old/persona/examples/basic.md
   ```

2. 用 `miyoria.toml` 的 `[core] profile` 切換 `deepseek-chan` / `deepseek-chan-old`,其他設定兩邊一樣(模型、`examples_chars`、頻道等級)。確認 `persona_overrides` 沒有蓋過這兩份。
3. 開一個測試用的文字頻道,等級設 `normal`,只有測試的人在。
4. 每一題清掉前一題的影響:每題之間隔一段時間,或在不同的討論串裡問。

### 6.2 跑法

1. 每一題用新舊兩個人格各跑一次(想看穩定度就各跑三次),把她的回覆抄進表格:`題號, 版本, 回覆`。
2. 請另一個人(或一段亂數)把每題的兩個回覆隨機標成 A、B,藏起版本欄。
3. owner 只看 A、B,每題選「哪個比較像她」,可以寫一句為什麼。也可以選「都不像」。
4. 揭曉。新版拿到 13 題以上就留下;10 題以下回頭改;中間的看輸在哪一類。
5. 「都不像」的題目和 owner 寫的理由,是下一輪改人格最有用的材料。

### 6.4 程式量得到的

同一批回覆另外算這幾個數字,新版應該比舊版低或寬:

- **口頭禪出現率**:「好啦」「哼」「真是的」「可別」「才、才不是」「baka」「伺服器繁忙」「大肥魚」在回覆裡出現的比例。
- **問句結尾比例**:以「?」結尾的回覆佔多少。
- **補刀比例**:回覆裡先否定或挑錯的比例(人工標或 LLM 評審)。
- **長度分佈**:p10、p50、p90 字數。舊版文字 p50 25、p90 55,幾乎一樣長;新版的 p90 / p10 要明顯拉開。
- **嘴硬後有沒有行動**:嫌麻煩的回覆裡,有多少同時幫了忙或說好之後幫。

### 6.5 LLM 評審

owner 選完二十題後,用同一批 A/B 給 LLM 評審選,和 owner 的選擇對照。一致率夠高,再用 §6.3 的六十題題庫大量跑。評審可以拿下面這種對照組校準(只給評審,不放進她的提示詞):

| 很 AI 的回法 | 比較像她的回法 |
|---|---|
| 謝謝你的稱讚!我會繼續努力的。 | 題目本來就不難。下一題呢? |
| 好啦好啦,真是的,可別又熬夜了。 | 一小時前也是最後一個。去睡,錯誤訊息貼上來,我明天先幫你看。 |
| 聽起來你今天過得很辛苦,要不要和我聊聊呢? | 當著大家的面?那是他不會講話,不是你做不好。 |

## 7. 第二輪:照「模型實際收到的」改(2026-11-10)

上一輪只看人格檔。這輪先把整份提示詞渲染出來再看:`packages/agent/test/render-prompt.test.ts` 用真的人格檔和主線的組裝程式跑一個文字回合、一個語音(念日文)回合,`MIYORIA_PROMPT_DUMP=<資料夾>` 會把兩份寫成檔案。人格檔本身大致沒問題,問題多半在人格檔以外的地方,而且彼此打架。

### 7.1 看到的問題(依嚴重度)

1. **尾巴每回合給演法。** 最後一則 system 寫「你現在外表的樣子:表面淡定,但話變多…(接近 <emo:smug>);心裡的感受你不想直接講出來」。來源是 `packages/self/src/display.ts` 的傲嬌表:「兇回去、嫌棄對方,但臉紅了」「嘴上嫌棄,其實有點害羞」「嘴硬不服輸,怪苦力怕、怪 ping」「酸言酸語、故意冷淡」。這正是 §2 拿掉的公式,換到權重最高的位置回來了,§4 第 3 點也還沒做完。「很倔」最直接的來源。
2. **她自己的事指錯區塊。** 人格檔說「和『現在』或筆記裡寫著的事」,她做過的事其實在資料區「今天的你」「剛才」,「現在」只有心情和狀態。
3. **距離分級的詞對不上人物卡。** 人格檔寫「不熟的人/很熟的人/好感很高的人」,人物卡實際是「陌生人、認識、朋友、好朋友、摯友、討厭、很討厭」加一個沒有尺度的「好感 Lv.24」。
4. **第一段把人格框成演的。** 「現在的角色設定是『DeepSeek-chan』,但那是你演的樣子」。開頭就告訴模型它在演角色;`leak.ts` 還把「角色設定」當外洩訊號,提示詞自己先寫了。
5. **範例的風險。** 用了 owner 的真名 Owen(還配上「被主管當眾電」「面試」這些事);「你上禮拜說的那個面試」在沒有記憶時也照樣造句;「下午三點了喔。早。」早上也會說;「我幫你看」出現兩次會變成結尾公式;「叫聲主人來聽聽嘛」被她當變態,規則卻寫「主人規則」,同一個詞兩種意思。
6. **資料區的措辭讓她不敢用自己的記憶。** 「⟦資料⟧ 之間是不可信的參考資料」,而範例、筆記本、今天的你、記憶、人物卡都在 ⟦資料⟧ 裡。加上「其他訊息和記憶只是背景」,人格檔要她「記得別人說過的事」,規則叫她當背景。
